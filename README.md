# Crypto ATL Scanner

Локальный скринер криптовалют. Он находит монеты, которые торгуются около своего
исторического минимума (ATL), и собирает их метрики. Это материал для исследования
гипотезы `STABLE → PUMP → DUMP → STABLE → PUMP → FINAL DUMP`. Гипотеза **не проверена**,
и выдача скринера **не является торговыми сигналами**.

Монета попадает в выборку, если одновременно:
- её капитализация выше порога (по умолчанию $20M);
- её возраст больше года (есть цена или свеча старше 365 дней);
- она не стейблкоин, не wrapped- или bridged-токен и не токенизированный реальный актив.

Затем монеты сортируются по расстоянию до ATL. Порог «около ATL» по умолчанию не задан:
вы выбираете его сами.

Данные берутся из двух бесплатных источников:
- **CoinGecko** — список монет, капитализация, ATL за всю историю. Нужен бесплатный ключ.
- **Binance** — часовые свечи за последний год. Ключ не нужен.

Всё работает на вашем компьютере, без серверов и облака.

## 1. Что нужно заранее

| Что | Зачем | Где взять |
|---|---|---|
| Windows 10/11, macOS или Linux | | инструкция ниже для Windows (PowerShell); для macOS/Linux — отличия в сносках |
| Git | скачать проект | https://git-scm.com/downloads |
| uv | ставит Python и зависимости | шаг 2.2 |
| Ключ CoinGecko Demo API | список монет и ATL | шаг 3, бесплатно |

Python ставить отдельно не нужно: если подходящей версии (3.11+) нет, `uv` скачает её сам.

## 2. Установка

### 2.1 Скачать проект

Откройте PowerShell и выполните:

```powershell
cd C:\projects
git clone https://github.com/stanlaktionov/atl-scanner.git
cd atl-scanner
```

Папка может быть любой. Дальше все команды выполняются **из папки проекта**.

### 2.2 Установить uv

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

Закройте и снова откройте PowerShell, затем проверьте:

```powershell
uv --version
```

> macOS/Linux: `curl -LsSf https://astral.sh/uv/install.sh | sh`.
> Если uv уже стоит через `pip install uv`, но команда `uv` не находится, пишите
> `python -m uv` вместо `uv` во всех командах ниже.

### 2.3 Установить зависимости

```powershell
uv sync --extra ui
```

Команда создаст папку `.venv` и установит туда всё нужное, включая веб-страницу (`--extra ui`).
Обновлять зависимости потом нужно **этой же** командой: без `--extra ui` веб-страница удалится.

Проверьте установку:

```powershell
uv run atl-scanner --help
```

Должен появиться список команд: `scan`, `fetch`, `screen`, `coin`, `dq`, `ui`, `check-config`.

## 3. Ключ CoinGecko

1. Зарегистрируйтесь на https://www.coingecko.com (бесплатно).
2. Откройте **Developer Dashboard**: https://www.coingecko.com/en/developers/dashboard
3. Создайте ключ тарифа **Demo** (Add New Key). Ключ выглядит как `CG-xxxxxxxxxxxxxxxxxxxxxxxx`.

Ограничения бесплатного тарифа: 10 000 вызовов в месяц и 100 в минуту. Один прогон
скринера тратит около 10–20 вызовов, так что запаса хватит на сотни прогонов в месяц.

## 4. Настройка

### 4.1 Файл `.env` — ключ

```powershell
copy .env.example .env
notepad .env
```

Впишите ключ и сохраните:

```
COINGECKO_API_KEY=CG-xxxxxxxxxxxxxxxxxxxxxxxx
```

`.env` не попадает в git. Не публикуйте ключ.

### 4.2 Файл `config.yaml` — параметры отбора

```powershell
copy config.example.yaml config.yaml
uv run atl-scanner check-config
```

`check-config` проверит файл и покажет главные пороги. В `config.yaml` хранятся все параметры,
в коде их нет. Править можно любым редактором; после правки снова запустите `check-config`.

Чаще всего меняют эти параметры:

| Параметр | По умолчанию | Что значит |
|---|---|---|
| `universe.min_market_cap_usd` | `20000000` | минимальная капитализация, $ |
| `universe.min_age_days` | `365` | минимальный возраст монеты, дней |
| `screen.near_atl.metric` | `dist_log` | как мерить расстояние до ATL: `dist_pct`, `dist_log` или `dist_atr` (см. раздел 6) |
| `screen.near_atl.atl_source` | `coingecko_all_time` | какой ATL брать: `coingecko_all_time` (за всю историю) или `binance_1y` (минимум Binance за год) |
| `screen.near_atl.max` | `null` | порог «около ATL»; `null` — только сортировка, без отсечения |
| `screen.require_binance_pair` | `false` | `true` — только монеты, которые торгуются на Binance |
| `screen.require_age` | `true` | `false` — пропускать монеты, возраст которых не удалось доказать |
| `metrics.atr_period` | `14` | период ATR для `dist_atr` |
| `metrics.new_low_window_days` | `30` | окно для признака «новый минимум за N дней» |
| `exclusions.ids` | `[]` | id CoinGecko, которые нужно исключить вручную |
| `exclusions.keep_ids` | `[]` | id, которые нельзя исключать, даже если они попали в категорию исключений |
| `mapping.overrides` | `{}` | ручное сопоставление: `cg-id: ABCUSDT`, или `cg-id: null` — «нет пары» |
| `report.md_top_n` | `50` | сколько монет показывать в Markdown-отчёте |

Например, оставить только монеты не дальше 20 % от исторического ATL и с парой на Binance:

```yaml
screen:
  near_atl:
    metric: dist_pct
    atl_source: coingecko_all_time
    max: 0.2
  require_age: true
  require_binance_pair: true
```

Остальные секции (`sources`, `http`, `storage`, `dq`) — это лимиты API, повторы запросов,
пути к файлам и пороги проверки качества. Менять их обычно не нужно; каждая строка
прокомментирована в `config.example.yaml`.

## 5. Первый запуск

```powershell
uv run atl-scanner scan
```

Что произойдёт:
1. Загрузится список монет из CoinGecko (около 10 вызовов) и применятся исключения.
2. Монеты сопоставятся с парами Binance.
3. Скачаются часовые свечи Binance за год. **В первый раз это ~15 минут** (около 300 пар,
   2.6 млн свечей). Прогресс выводится в терминал. Потом докачиваются только новые часы,
   и скан занимает около минуты.
4. Посчитаются метрики, применятся фильтры, запишется отчёт в `data/reports/`.

Все данные лежат в папке `data/`: база `scanner.duckdb`, сырые ответы API и отчёты.
Чтобы начать с нуля, удалите папку `data/`.

## 6. Как пользоваться

### Веб-страница

```powershell
uv run atl-scanner ui
```

Браузер откроется на http://localhost:8501. Страница доступна только с вашего
компьютера. Остановить — `Ctrl+C` в терминале.

- **Боковая панель:**
  - «Полный скан» — то же, что `scan`;
  - «Пересчитать отбор» — пересчёт без сети по уже загруженным данным.
- **Вкладка «Отбор»:**
  - таблица монет и воронка фильтров;
  - переключатели метрики, источника ATL, порога, «только с парой Binance»;
  - кнопка, чтобы сохранить текущие настройки как отчёт.

  Изменения на странице `config.yaml` не трогают.
- **Вкладка «Монета»:** поиск монеты, её метрики и график цены за год с линиями обоих ATL.
- **Вкладка «Качество данных»:** проверка пропусков свечей, свежести, расхождения ATL и т. п.
- **Вкладка «Прогоны и отчёты»:** история запусков, просмотр и скачивание отчётов.

### Командная строка

| Команда | Что делает | Сеть |
|---|---|---|
| `uv run atl-scanner scan` | загрузка, отбор и отчёт — обычный запуск | да |
| `uv run atl-scanner screen` | пересчитать отбор с текущим `config.yaml`, записать отчёт | нет |
| `uv run atl-scanner screen --top 30` | то же, вывести 30 монет в терминал | нет |
| `uv run atl-scanner coin atom` | карточка одной монеты: тикер, id CoinGecko, пара Binance или название | нет |
| `uv run atl-scanner dq` | проверка качества данных | нет |
| `uv run atl-scanner fetch` | только загрузить и обновить данные | да |
| `uv run atl-scanner fetch --no-candles` | обновить список монет и сопоставление без свечей | да |
| `uv run atl-scanner check-config` | проверить `config.yaml` | нет |

Типичный порядок работы:
1. `scan` — раз в день или когда нужны свежие данные.
2. Правите пороги в `config.yaml`, затем `screen` — сколько угодно раз, это без сети и быстро.
3. Смотрите отдельные монеты через `coin <тикер>` или на веб-странице.
4. Перед тем как доверять выборке, запускаете `dq`.

Если тикер принадлежит нескольким монетам (например `meme`), `coin` выведет список
id CoinGecko. Повторите команду с нужным id: `uv run atl-scanner coin memecoin-2`.

### Отчёты

После `scan` и `screen` в `data/reports/` появляются два файла:
- **`<run_id>.md`** — параметры прогона, воронка, таблица лучших монет, расшифровка колонок.
  В VS Code открывается с предпросмотром по `Ctrl+Shift+V`.
- **`<run_id>.csv`** — все монеты со всеми метриками. Первая строка — комментарий с
  атрибуцией CoinGecko. В Excel её можно удалить; в pandas читать так:
  `pd.read_csv(path, comment="#")`.

### Что значат метрики

- **CG** — ATL CoinGecko за всю историю по всем биржам.
- **BN** — минимальная цена закрытия часовой свечи Binance за последний год.
- **dist %** = (цена − ATL) / ATL. Например, 0.25 — цена на 25 % выше ATL.
- **dist log** = ln(цена) − ln(ATL). Удобна для сравнения монет с очень разными ценами.
- **dist ATR** = (цена − ATL) / ATR(14) на 1h — сколько «типичных часовых движений» до ATL.
- **Новый минимум** — годовой минимум Binance установлен за последние N дней.
- **Расхождение ATL** = ln(ATL Binance) − ln(ATL CoinGecko). Ожидается ≥ 0; если меньше нуля,
  проверьте монету через `dq` или `coin`.
- **Возраст:**
  - `binance_first_candle` и `coingecko_atl_or_ath_date` — возраст доказан;
  - `unknown` — доказательств нет. Это не обязательно молодая монета.

## 7. Если что-то не работает

| Симптом | Причина и решение |
|---|---|
| `uv` не найден | перезапустите PowerShell после установки или пишите `python -m uv ...` |
| `COINGECKO_API_KEY is not set` | нет файла `.env` или в нём пустой ключ (шаг 4.1) |
| `401` / `check the API key` от CoinGecko | ключ неверный или отозван; создайте новый в Developer Dashboard |
| `max N calls per run reached` | сработала защита месячной квоты CoinGecko; увеличьте `sources.coingecko.max_calls_per_run`, если это ожидаемо |
| `451` от Binance | Binance недоступен из вашего региона; в `sources.binance.base_url` попробуйте `https://data-api.binance.vision` (стоит по умолчанию) или `https://api.binance.com` |
| `418` от Binance | IP временно заблокирован за превышение лимитов; подождите и уменьшите `sources.binance.weight_budget_per_min` |
| ошибка блокировки файла `scanner.duckdb` | база занята другим процессом: дождитесь окончания `scan` в другом окне или остановите веб-страницу |
| `atl-scanner ui`: Streamlit is not installed | выполните `uv sync --extra ui` |
| русский текст выводится «кракозябрами» | используйте Windows Terminal или PowerShell 7; приложение пишет в UTF-8 |
| хочется начать заново | удалите папку `data/` и запустите `scan` |
