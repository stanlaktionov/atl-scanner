# План реализации

**Статус (2026-10-10): шаги 0–11 выполнены**, плюс команда `atl-scanner coin`.

Каждый шаг заканчивается проверяемым результатом. Следующий шаг — только после зелёных тестов.

| # | Шаг | Проверяемый результат |
|---|---|---|
| 0 | Окружение: `uv sync`, `ruff`, `mypy`, `pytest` | `uv run pytest` зелёный (smoke-тест импортов), `uv run atl-scanner --help` печатает команды |
| 1 | `config.py`: pydantic-модели всех секций YAML, загрузка `.env` | тест: `config.example.yaml` валиден; неизвестный ключ/отрицательный порог → понятная ошибка |
| 2 | `sources/http.py`, `ratelimit.py`, `cache.py`: ретраи (429/5xx, `Retry-After`, экспоненциальная пауза), лимитер, raw-кэш | тесты на `httpx.MockTransport`: 2×429 → успех; кэш-хит не делает запрос; raw-файл появился в `data/raw/` |
| 3 | `sources/coingecko.py`: `/coins/markets` с остановкой по капитализации, категории исключений, счётчик вызовов | тест на фикстурах: пагинация останавливается; `atl-scanner fetch --only coingecko` печатает число монет и вызовов (≤ бюджета) |
| 4 | `store/db.py` + `normalize/coingecko.py`: схема DuckDB, upsert `coins`, `market_snapshots`, `runs` | тест: повторная загрузка тех же данных не дублирует строки; типы колонок как в ARCHITECTURE.md |
| 5 | `exclusions.py`, `mapping.py`: исключения с причиной, CG ↔ Binance со статусами | тесты: стейблкоин исключён с `category:stablecoins`; коллизия символов → `ambiguous`; override → `manual`; монета без пары → `no_pair` |
| 6 | `sources/binance.py` + `normalize/binance.py`: 1h-свечи за ≤ 1 год, инкремент, ресемплинг в 2h | тесты: пагинация `startTime`; инкремент докачивает только хвост; 2h-ресемпл = ручной расчёт OHLCV |
| 7 | `metrics/`: ATR (Уайлдер), `dist_pct/log/atr`, new-low за N дней, `days_since_atl`, расхождение ATL, возраст | тесты с ручным расчётом + крайние случаи (price == ATL → 0; ATL ≤ 0 → NaN; история < N → NaN ATR) |
| 8 | `screen.py`: фильтры из конфига → `screen_results`; `passes_near_atl = NULL` без порога | тест на синтетике: каждый фильтр включается/выключается конфигом; `config_hash` в `runs` |
| 9 | `report.py` + `atl-scanner scan`: CSV + Markdown с атрибуцией, сводка бюджета | реальный прогон: отчёт в `data/reports/<run_id>.*`, `runs.cg_calls` в пределах бюджета |
| 10 | `quality.py` + `atl-scanner dq`: пропуски свечей, нулевой объём, расхождение ATL, статусы mapping/age | отчёт DQ на реальных данных; тесты на синтетике с дырами в свечах |
| 11 | Streamlit-страница: отбор с фильтрами, карточка монеты с графиком, dq, прогоны и отчёты, кнопки scan/screen | `atl-scanner ui` открывает страницу; headless-тесты `tests/test_app.py` |

## Идеи на потом
Всё ниже — **гипотезы или расширения, не проверено и не входит в MVP.**
- *(гипотеза, не проверено)* объём/рост объёма как предвестник пампа.
- *(гипотеза, не проверено)* соцсети, sentiment, упоминания как фактор.
- *(гипотеза, не проверено)* обязательность второго пампа в паттерне.
- Детекция фаз STABLE/PUMP/DUMP по истории свечей (следующий этап).
- Бэктест / событийный анализ паттерна на исторических данных.
- Дополнительные биржи (Bybit, OKX, Gate) для охвата монет без пары на Binance.
- Платный план CoinGecko или другой источник для истории > 1 года.
- Учёт делистинговых монет, чтобы уменьшить survivorship bias.
- Алерты (Telegram/почта) после появления проверенной логики.
